# События HelpersNew

`utility_helpers::new_helpers::event::Signal<void(TArgs...)>` — синхронное событие C++17. Заголовок: `<HelpersNew/Event/Signal.h>`.

```cpp
namespace event = utility_helpers::new_helpers::event;

event::Signal<void()> stateChanged;
event::Connection connection = stateChanged.Subscribe([] {
    // Обновляем данные подписчика.
});
stateChanged.Invoke();
connection.Disconnect();
```

`Connection` хранится у подписчика, не копируется и автоматически отключается при уничтожении. Перемещение передаёт владение подпиской; присваивание отключает предыдущую подписку. Результат `Subscribe` необходимо сохранить. Уничтожение события делает оставшиеся подключения неактивными. `DisconnectAll` отключает текущие подключения, но позволяет подписаться заново.

Для публичного доступа к подписке используйте `IEvent<void(...)>&`: этот интерфейс не позволяет вызывать событие. Начальное состояние подписчик читает отдельно после подписки.

Обработчики вызываются в порядке подписки и вне блокировки. Подписка во время рассылки участвует в следующем вызове; отключённый до проверки активности обработчик пропускается. Повторный `Invoke` из обработчика поддерживается. Исключение обработчика передаётся вызывающему и прекращает текущую рассылку. Значения аргументов копируются каждому обработчику; ссылочные аргументы сохраняют ссылку. Перемещаемые без копирования значения и rvalue-ссылки не поддерживаются.

Разные потоки могут подписываться, вызывать событие и отключать разные подключения. Параллельные рассылки могут одновременно вызвать один обработчик. `Disconnect` не ожидает завершения обработчика и не является барьером уничтожения объекта, захваченного через `this`: для таких объектов требуется отдельная синхронизация или слабый указатель. Одновременное изменение одного объекта `Connection`, как и уничтожение `Signal` одновременно с обращением к нему, требует внешней синхронизации. Доставка в поток интерфейса выполняется хостом.

Тесты включаются опцией CMake `HELPERS_NEW_BUILD_TESTS=ON`. Цель: `helpers_new_signal_tests`.
